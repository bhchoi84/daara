# 마케팅 최적화 설계

## Context
한국 운세/사주 앱 시장(1.4조원) 분석 결과, 점신(1900만 DL)·헬로우봇·포스텔러 등 상위 앱 대비 다아라의 마케팅 카피, 소셜 프루프, 전환 퍼널이 약함. 감정 트리거 + 소셜 증거 + 전환 최적화를 적용하여 경쟁력 강화.

## 2. 소셜 프루프

### 수정 파일: `js/app.js`, `index.html`

#### 2-1. 소셜 카운터 유틸 함수 (`js/app.js`)

```javascript
function getSocialCount(type) {
  const hour = new Date().getHours();
  const dayOfYear = Math.floor((Date.now() - new Date(new Date().getFullYear(),0,0)) / 86400000);
  const seed = dayOfYear * 100 + hour;
  const pseudo = ((seed * 9301 + 49297) % 233280) / 233280;

  const ranges = {
    consulting: [80, 280],   // 광고 슬롯: "오늘 N명이 상담 중"
    premium: [50, 150],      // 결제 모달: "이번 주 N명이 프리미엄 시작"
  };
  const [min, max] = ranges[type] || [50, 200];

  // 시간대 가중치: 아침 낮음, 저녁 높음
  const timeWeight = hour < 8 ? 0.4 : hour < 12 ? 0.7 : hour < 18 ? 0.85 : 1.0;
  return Math.floor(min + (max - min) * pseudo * timeWeight);
}
```

#### 2-2. 광고 슬롯 동적 업데이트
- DOMContentLoaded에서 `.ad-body` 텍스트를 `오늘 {getSocialCount('consulting')}명이 상담 중`으로 설정

#### 2-3. 인기 상담 힌트 (웰컴 메시지 하단)
- 요일별 추천: 월~목 "오늘의 운세", 금~토 "연애 궁합", 일 "별자리 운세"
- 웰컴 메시지 끝에 추가: `<br><span style="font-size:11px;color:var(--text-muted)">지금 가장 많이 받는 상담: {추천} 🔥</span>`
